Pon aquí las fotos de los platos.

El nombre de cada archivo tiene que coincidir EXACTAMENTE con el que
aparece en el campo "imagen" del plato, dentro de js/menu-data.js.

Ejemplos:
  images/edamame.jpg
  images/nigiri-de-salmon.jpg
  images/uramaki-dragon.jpg

Recomendación: fotos cuadradas (misma proporción) para que la carta
se vea uniforme al deslizar entre platos.
